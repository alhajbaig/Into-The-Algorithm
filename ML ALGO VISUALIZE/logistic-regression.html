01 — Understanding

What is Logistic Regression?

🎯

The Idea

Logistic Regression models the probability of a binary outcome using the sigmoid function. Unlike linear regression which predicts continuous values, logistic regression outputs probabilities bounded between 0 and 1.

📐

The Sigmoid Function

The core transformation that maps any real number to (0, 1):

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

where \(z = \beta_0 + \beta_1 x\). The output \(\sigma(z)\) represents the probability of belonging to class 1.

📉

Cost Function

We minimise the Binary Cross-Entropy (Log Loss) — which penalises confident wrong predictions heavily:

$$J = -\frac{1}{n}\sum_{i=1}^{n}\bigl[y_i\log(\hat{p}_i) + (1-y_i)\log(1-\hat{p}_i)\bigr]$$
⚡

Gradient Descent

Parameters are updated iteratively using gradient descent:

$$\beta_j := \beta_j - \alpha \frac{\partial J}{\partial \beta_j}$$

where the gradient is:

$$\frac{\partial J}{\partial \beta_j} = \frac{1}{n}\sum_{i=1}^{n}(\hat{p}_i - y_i)x_{ij}$$

🔑 Key Assumptions

1
Binary Outcome

The dependent variable is binary (0 or 1).

2
Independence

Observations are independent of each other.

3
Linearity in Log-Odds

Linear relationship between features and log-odds.

4
No Multicollinearity

Independent variables should not be highly correlated.
