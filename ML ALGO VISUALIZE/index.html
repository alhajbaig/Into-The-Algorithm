01 — Understanding

What is Linear Regression?

🎯

The Idea

Linear Regression models the relationship between a dependent variable \(y\) and one or more independent variables \(x\) by fitting a straight line (or hyper-plane) that minimises the prediction error.

📐

The Equation

For simple (one-variable) linear regression the model is:

$$\hat{y} = \beta_0 + \beta_1 x$$

where \(\beta_0\) is the intercept (bias) and \(\beta_1\) is the slope (weight).

📉

Cost Function

We minimise the Mean Squared Error (MSE) — the average of squared differences between predicted and actual values:

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$
⚡

Closed-Form Solution

The optimal coefficients can be found analytically using the Normal Equation:

$$\beta_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}$$
$$\beta_0 = \bar{y} - \beta_1\bar{x}$$

🔑 Key Assumptions

1
Linearity

The relationship between X and Y is linear.

2
Independence

Observations are independent of each other.

3
Homoscedasticity

Constant variance of residuals across all levels of X.

4
Normality

Residuals are approximately normally distributed.
