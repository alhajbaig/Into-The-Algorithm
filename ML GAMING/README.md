# ML Quest

Candy Crush–style machine learning interview prep: **quizzes**, **flashcards**, **interview prompts**, and **coding challenges** — level-gated, with streaks, badges, coins, stars, and voice cheers.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## How it works

- Clear **all modes** on a level to unlock the next (Candy Crush progression).
- Quizzes need **≥ 50%** to count as cleared; perfect scores earn more stars/coins.
- Progress, streaks, and badges save in `localStorage`.
- After quizzes / coding / flashcards / interviews, the browser **speaks** a cheer (allow voice if prompted).

## Content sources

Question themes adapted from:

- [machine-learning-interview-questions](https://github.com/amitshekhariitbhu/machine-learning-interview-questions)
- [DataCamp — Top ML Interview Questions](https://www.datacamp.com/blog/top-machine-learning-interview-questions)

Levels cover: general fundamentals, regression, algorithms, preprocessing, deep learning, evaluation, NLP, computer vision, coding, and advanced / LLM interview topics.
