# Into the Algorithm

Unified ML learning platform combining:

- **Algorithm Lab** — interactive visualizations (Linear Regression, Logistic Regression, K-Means)
- **ML Quest** — gamified interview prep (quizzes, flashcards, coding, badges)

Original folders `ML ALGO VISUALIZE` and `ML GAMING` are unchanged; this `app` folder is the single combined project.

## Run

```bash
cd app
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

| Path | What |
|------|------|
| `/` | Hub |
| `/learn/main.html` | Algorithm Lab |
| `/learn/kmeans.html` | K-Means |
| `/quest` | ML Quest map |
| `/quest/badges` | Badges |
