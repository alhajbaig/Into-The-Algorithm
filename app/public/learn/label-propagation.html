01 — Theory & Foundations

House of Knowledge

RBF similarity matrices, Normalized Graph Laplacians, and exact harmonic fixed-point solutions.

📐

1. RBF Similarity Matrix (\(\mathbf{W}\))

Edge affinity between nodes \(x_i\) and \(x_j\) computed via Gaussian Radial Basis Function kernel:

$$W_{ij} = \exp\left(-\gamma \|x_i - x_j\|^2\right) \quad \text{for } i \ne j, \quad W_{ii} = 0$$
🔄

2. Probabilistic Transition (\(\mathbf{P}\))

Normalizes row affinities by diagonal degree matrix \(D_{ii} = \sum_j W_{ij}\) into Markov transition matrix:

$$\mathbf{P} = \mathbf{D}^{-1} \mathbf{W}, \quad P_{ij} = \frac{W_{ij}}{\sum_k W_{ik}}$$
⚡

3. Label Spreading Update (\(\alpha\))

Iteratively updates node probabilities with clamping parameter \(\alpha \in (0, 1)\) preserving initial seeds:

$$\mathbf{Y}^{(t+1)} = \alpha \mathbf{S} \mathbf{Y}^{(t)} + (1 - \alpha) \mathbf{Y}^{(0)}$$
🔮

4. Closed-Form Fixed Point

As \(t \to \infty\), system converges directly to harmonic function solution on graph manifold:

$$\mathbf{Y}^* = (1 - \alpha) (\mathbf{I} - \alpha \mathbf{S})^{-1} \mathbf{Y}^{(0)}$$

💡 Interview & Production Guidelines

Q: Difference between Label Propagation and Label Spreading?

Label Propagation hard-clamps initial seed labels (\(\mathbf{Y}_L^{(t)} = \mathbf{Y}_L^{(0)}\)), whereas Label Spreading uses normalized Laplacian \(\mathbf{S} = \mathbf{D}^{-1/2}\mathbf{W}\mathbf{D}^{-1/2}\) and soft-clamping \(\alpha\), rendering it far more robust to noisy initial seeds.

Q: How to set RBF Hyperparameter \(\gamma\)?

Too large \(\gamma\) disconnects nodes into isolated components; too small \(\gamma\) turns graph into uniform noise. Tune via k-nearest neighbor distance heuristics.

📊 Algorithmic Comparison: Label Propagation vs Label Spreading vs KNN
