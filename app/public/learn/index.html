01 — Deep Intuition & Mathematical Formulations

Linear Regression: The House of Knowledge

Master every aspect of Linear Regression — from Ordinary Least Squares derivations and Gradient Descent optimization to Regularization ($L_1$/$L_2$) and diagnostic checks.

💡

Linear Regression for Beginners (Explain Like I'm 5)

Imagine you want to predict house prices based on house size. If you plot house sizes on the bottom (X-axis) and prices on the side (Y-axis), you get a scatter of dots. Linear Regression is like laying a physical straight ruler through those dots so that it passes as close to all dots as possible!

🏠 Baseline Price ($\beta_0$)

The starting price of a 0 sq ft lot. This is where the ruler crosses the vertical axis (Y-intercept).

📏 Price per Sq Ft ($\beta_1$)

How much extra value each additional square foot adds. This controls the steepness (slope) of your ruler.

🎯 Minimizing Errors (MSE)

We measure how far off our line is from each real dot, square those distances, and twist the ruler until total error is as tiny as possible!

🎯

1. Mathematical Formulation

Linear Regression assumes a linear relationship between input features \(X \in \mathbb{R}^{n \times p}\) and target vector \(y \in \mathbb{R}^n\):

$$\hat{y} = X\beta = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p$$

where \(\beta_0\) represents the bias/intercept and \(\beta_1 \dots \beta_p\) represent feature weights.

📉

2. Loss Function (MSE)

We minimize the Mean Squared Error (MSE) cost function \(J(\beta)\), which quantifies average squared prediction error:

$$J(\beta) = \frac{1}{2n} \sum_{i=1}^{n} (y_i - x_i^T \beta)^2 = \frac{1}{2n} \|y - X\beta\|^2$$

The factor of \(\frac{1}{2}\) simplifies calculations during gradient derivation.

⚡

3. Closed-Form Solution (Normal Eq)

Setting \(\nabla_\beta J(\beta) = 0\) yields the exact analytical solution via matrix calculus:

$$\beta^* = (X^T X)^{-1} X^T y$$

Computational complexity is \(\mathcal{O}(p^3)\) to invert \(X^T X\). Requires \(X^T X\) to be non-singular.

🔄

4. Gradient Descent Derivation

Taking partial derivatives of \(J(\beta)\) with respect to weight \(\beta_j\):

$$\frac{\partial J}{\partial \beta_j} = \frac{1}{n}\sum_{i=1}^n (\hat{y}_i - y_i) x_{i,j}$$

Weights update iteratively via: \(\beta_j := \beta_j - \alpha \frac{\partial J}{\partial \beta_j}\).

🛡️

5. Regularization ($L_1$ vs $L_2$)

Prevents overfitting by penalizing large weight magnitudes:

$$\text{Ridge (L2): } J(\beta) + \lambda \|\beta\|_2^2 = J(\beta) + \lambda \sum_{j=1}^p \beta_j^2$$
$$\text{Lasso (L1): } J(\beta) + \lambda \|\beta\|_1 = J(\beta) + \lambda \sum_{j=1}^p |\beta_j|$$

Lasso produces sparse weights (feature selection); Ridge shrinks weights smoothly.

📊

6. Evaluation Metrics

Key metrics to evaluate goodness of fit:

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$
$$\text{Adjusted } R^2 = 1 - (1 - R^2)\frac{n - 1}{n - p - 1}$$

Adjusted \(R^2\) penalizes adding irrelevant features that artificially inflate raw \(R^2\).

🔑 The 4 LINE Assumptions & Diagnostics

L
Linearity

Linear relationship between predictors and response. Verify via Scatter plots & Residual vs Fitted plots.

I
Independence

Residual errors are uncorrelated. Check Durbin-Watson statistic for time-series autocorrelation.

N
Normality of Errors

Residuals follow \(\mathcal{N}(0, \sigma^2)\). Verify using Normal Q-Q Plot and Shapiro-Wilk test.

E
Equal Variance (Homoscedasticity)

Constant residual spread across predictions. Non-constant spread indicates heteroscedasticity.

💡 Interview & Production Guidelines

Q: Why prefer Gradient Descent over Normal Equation?

Inverting \((X^T X)\) takes \(\mathcal{O}(p^3)\) time and \(\mathcal{O}(p^2)\) memory. When feature count \(p > 10,000\), matrix inversion becomes computationally intractable, whereas Gradient Descent runs efficiently in \(\mathcal{O}(k \cdot n \cdot p)\).

Q: What causes Multicollinearity and how to fix it?

When features are highly correlated, \((X^T X)\) becomes nearly singular (determinant \(\approx 0\)), causing extreme weight variance. Fix by using Ridge Regularization ($L_2$) or removing features via Variance Inflation Factor (VIF > 10).

Q: How does Lasso ($L_1$) perform feature selection?

The $L_1$ norm constraint region is a diamond with sharp corners along feature axes. Contours of MSE loss hit the sharp corners first, forcing non-essential weights strictly to zero.

Q: Time & Space Complexity Summary

Training Complexity: Normal Eq \(\mathcal{O}(p^3 + np^2)\); Gradient Descent \(\mathcal{O}(epochs \cdot np)\).
Inference Complexity: \(\mathcal{O}(p)\) dot product per prediction.
Storage: \(\mathcal{O}(p)\) weights.

📊 Algorithmic Comparison: OLS vs Ridge vs Lasso

Method Penalty Term Closed-Form Solution? Feature Selection (Sparsity)? Best Used When
OLS (Ordinary Least Squares) None Yes: \(\beta = (X^T X)^{-1} X^T y\) No Features are un-correlated and \(p \ll n\).
Ridge Regression ($L_2$) \(\lambda \sum \beta_j^2\) Yes: \(\beta = (X^T X + \lambda I)^{-1} X^T y\) No (shrinks towards zero) High multicollinearity exists between features.
Lasso Regression ($L_1$) \(\lambda \sum |\beta_j|\) No (Iterative Subgradient / Coordinate Descent) Yes (sets coefficients to 0) Many irrelevant features exist (\(p \gg n\)).
