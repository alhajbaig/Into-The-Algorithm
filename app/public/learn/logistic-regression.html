01 — Deep Intuition & Mathematical Formulations

Logistic Regression: The House of Knowledge

Master Logistic Regression — from Sigmoid activation and Log-Odds interpretations to Binary Cross-Entropy Loss, Maximum Likelihood Estimation, and ROC-AUC evaluation metrics.

💡

Logistic Regression for Beginners (Explain Like I'm 5)

Imagine checking an email to decide if it is Spam (1) or Not Spam (0). Linear Regression is bad here because it can output crazy numbers like 150% or -30%. Logistic Regression uses an S-shaped curve (Sigmoid) that squashes any score into a clean probability between 0% and 100%!

🌊 The S-Curve (Sigmoid)

Takes any real number $z$ (from $-\infty$ to $+\infty$) and bends it smoothly into a percentage between 0.0 (0%) and 1.0 (100%).

⚖️ The 50% Threshold

If predicted probability $P \ge 50\%$, we classify as Class 1 (Spam). If $P < 50\%$, we classify as Class 0 (Not Spam).

❌ Log-Loss Penalty

If the model is 99% confident an email is safe, but it turns out to be a virus, Log-Loss inflicts a huge mathematical penalty!

⚡

1. The Sigmoid Activation

Logistic regression transforms linear combinations \(z = w^T x + b\) into probability outputs \(p \in (0,1)\) using the logistic (sigmoid) function:

$$\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}$$

When \(z=0\), \(\sigma(0) = 0.5\). Derivative: \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\).

🎲

2. Odds Ratio & Log-Odds

The ratio of probability of success vs failure is the Odds. Taking the natural logarithm gives the linear Log-Odds (Logit):

$$\text{Odds} = \frac{p}{1-p} \implies \ln\left(\frac{p}{1-p}\right) = w^T x + b$$

Thus, weights \(w_j\) represent the change in log-odds for a unit change in feature \(x_j\).

📉

3. Binary Cross-Entropy Loss

Mean Squared Error is non-convex for logistic regression. Instead, we use Log-Loss (Binary Cross-Entropy):

$$J(w,b) = -\frac{1}{n}\sum_{i=1}^n \left[ y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i) \right]$$

Penalizes confident wrong predictions exponentially (e.g. predicting \(\hat{y} \to 1\) when actual \(y=0\)).

🎯

4. Maximum Likelihood (MLE)

Assuming Bernoulli trials, likelihood function \(L(w,b)\) maximized by parameter estimation is:

$$L(w,b) = \prod_{i=1}^n \hat{y}_i^{y_i} (1-\hat{y}_i)^{1-y_i}$$

Maximizing log-likelihood \(\log L(w,b)\) is mathematically equivalent to minimizing Binary Cross-Entropy Loss.

🌐

5. Decision Boundary

The default decision threshold is \(p = 0.5\), which corresponds to \(z = w^T x + b = 0\):

$$\text{Predict } \hat{y} = \begin{cases} 1 & \text{if } w^T x + b \ge 0 \\ 0 & \text{if } w^T x + b < 0 \end{cases}$$

In 2D feature space, this forms a straight line decision boundary \(w_1 x_1 + w_2 x_2 + b = 0\).

📊

6. Evaluation & Confusion Matrix

Evaluation relies on confusion matrix counts (TP, TN, FP, FN):

$$\text{Precision} = \frac{TP}{TP + FP}, \quad \text{Recall} = \frac{TP}{TP + FN}$$
$$F_1\text{-Score} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

ROC-AUC plots True Positive Rate vs False Positive Rate across all decision thresholds.

📊 Binary vs Multi-Class Logistic Regression

Type Activation Function Loss Function Output Probability Vector Best Used For
Binary Classification Sigmoid: \(\sigma(z) = \frac{1}{1 + e^{-z}}\) Binary Cross-Entropy (Log-Loss) Single scalar \(p \in (0, 1)\) Two outcome problems (Spam/Not Spam, Pass/Fail)
Multi-Class (Softmax) Softmax: \(\sigma(z)_k = \frac{e^{z_k}}{\sum e^{z_j}}\) Categorical Cross-Entropy \(K\)-dimensional probability vector summing to 1 Multi-class mutually exclusive labels (Digit 0-9)
Multi-Class (One-vs-Rest) \(K\) Independent Sigmoids Sum of \(K\) Binary Cross-Entropy losses \(K\) independent probabilities Multi-label classification (Image tagging)
